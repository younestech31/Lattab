# Notaire Lattab Mohamed Office Notarial

Office notarial de Maître Lattab Mohamed, Notaire à Oran, Algérie.

## Configuration & Deployment

### IndexNow Deploy Hook Setup

After deploying the application to Vercel, configure a Deploy Hook to automatically queue and submit all blog pages and static URLs to IndexNow (Bing, Yandex, etc.) immediately on successful builds:

1. **Get / Create your Hook Secret**:
   Generate a secure, random string to use as your `DEPLOY_HOOK_SECRET` env variable and set it in Vercel.

2. **Add Deploy Hook in Vercel**:
   - Go to your Project on Vercel.
   - Click on **Settings** → **Git**.
   - Under **Deploy Hooks**, click **Create Hook**.
   - Give it a descriptive name (e.g., `IndexNow Ping on Deploy`).
   - Use your branch (e.g., `main`).
   - Copy the hook URL generated by Vercel.

3. **Configure Webhook Trigger**:
   Set up your CI or deploy trigger to call `https://your-domain.com/api/deploy-hook` using POST, passing the header:
   `Authorization: Bearer DEPLOY_HOOK_SECRET`
